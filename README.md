# Foundations of Programming course at IST

# Project 1

** Goal: ** A Python project implementing a configurable MNK board game, inspired by the classic Tic-Tac-Toe. The project allows players to customize the board dimensions and the number of consecutive pieces required to win, while implementing three different computer strategies: easy, normal, and difficult. A practical project focused on abstract data types, board manipulation, game logic, position analysis, and algorithmic decision-making.


# Project 2

** Goal: ** A Python project implementing a configurable version of the board game Orbito, based on the m,n,k game model. The project focuses on fundamental programming concepts through the implementation of custom abstract data types, board manipulation, game mechanics, win detection, and automated move strategies. Players can choose the number of board orbits, their piece color, and different game modes, including playing against the computer or another human player. After each turn, all pieces rotate one position counter-clockwise along their respective orbits.
